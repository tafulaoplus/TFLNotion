ตั้งค่า Google Drive
วิธีรับ OAuth Client ID (ฟรี)
  1. ไปที่ Google Cloud Console
  2. สร้าง Project ใหม่ (หรือเลือกที่มีอยู่)
  3. เปิดใช้ Google Drive API ที่ APIs & Services → Library
  4. ไปที่ Credentials → Create Credentials → OAuth Client ID
  5. เลือก Type: Web application
  6. เพิ่ม Authorized JavaScript origins เช่น http://localhost:8000
  7. คัดลอก Client ID มาวางด้านล่าง
⚠ หมายเหตุ: Google OAuth ไม่ทำงานบน file:// URL — ต้องเปิดผ่าน http://localhost หรือเว็บจริง
เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน: python -m http.server 8000 แล้วเปิด http://localhost:8000
